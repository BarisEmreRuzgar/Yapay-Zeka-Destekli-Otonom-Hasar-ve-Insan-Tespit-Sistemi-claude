🌍 DisasterVision — afet hasarı ve insan tespiti

İHA (drone) veya uydu görüntüsü yükleyin: binalar 4 hasar seviyesinde sınıflanır, insanlar işaretlenir. Modeller (YOLOv8s) sizin tarayıcınızda çalışır; görüntü hiçbir sunucuya gönderilmez.

Kaynak kod, eğitim süreci ve bağımsız test sonuçları: GitHub deposu. Hasar: ana model (xBD + Roboflow); insan: arama-kurtarma verileriyle eğitilmiş uzman model (1280 px). Tarayıcı sürümü Python sürümüyle aynı modelleri kullanır; görüntü ölçekleme farkı nedeniyle sayılar birkaç kutu farklı olabilir.
Karar destek aracıdır; sonuçlar saha ekiplerince doğrulanmalıdır.
